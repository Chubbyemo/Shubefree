# Chubby Mouse — Clawd Buddy 像素主题 v2

Chubbyemo 的小老鼠（长尖鼻子、细身子、长尾巴）像素版。每个动作都参照她的一幅画：
写代码=面对老鼠编程 · 思考=乱糟糟的气泡 · 出错=哭成喷泉 · 完成=奶酪上开派对 · 要确认=瞪眼!! ·
打哈欠=张大嘴 · 打瞌睡=TIRED 咖啡杯 · 睡觉=趴在奶酪上 · 惊醒=吓一跳!! · 拖起来=吊绳子 ·
戳它=大眼瞪你 · 戳烦了=投降 · 双击=跳舞/升天 · 闲着=荡秋千/干杯/奶嘴/超级鼠/啃奶酪/东张西望

## 安装
1. git clone https://github.com/bestxiangest/clawd-buddy && cd clawd-buddy && npm install
2. 把 `chubby-mouse` 文件夹复制到 `clawd-buddy\themes\`
3. npm start → 右键 → Theme → Chubby Mouse
